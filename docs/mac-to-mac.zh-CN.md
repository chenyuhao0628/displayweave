# Mac 与 Mac 局域网互联

下列安装包说明对应 p8。当前源码另外支持[加密配对](secure-transport.zh-CN.md)和可选[接收端键鼠回传](mac-receiver-input.zh-CN.md)。

本功能已作为实验功能包含在 `v0.2.1-p7` 开发预览包中；双 Mac 实机性能及耐久验收仍待完成。
两台 Mac 都需要此构建和 macOS 14 或更新系统。任一 Mac 均可发送或接收，
每台同一时间只运行一个角色。

主窗口现在集中展示设备和连接模式。点击齿轮或 Command-comma 打开独立设置窗口，调整画质、应用显示方式、权限和诊断。主窗口可调整大小，菜单栏面板保持受控尺寸。

## 连接步骤

1. 两台 Mac 通过 Wi-Fi 或以太网接入同一局域网。路由器客户端隔离或不同的
   访客网络可能阻止发现与连接。
2. 接收 Mac 打开 DisplayWeave，选择 **接收屏幕**，选择此角色即开始接收。
   设置设备名称、接收显示器，以及是否全屏。
3. 发送 Mac 选择 **发送屏幕**，传输选 **Auto** 或 **局域网**，在设备列表
   选择接收 Mac。使用现有模式控件选择扩展或镜像。仅 USB 模式不会连接局域网。
4. 扩展模式下，在 macOS 系统设置 → 显示器中排列新显示器。
   使用发送 Mac 的键盘和鼠标；接收 Mac 只显示画面。
5. 关闭画面窗口或点击 **断开连接** 会结束当前会话，仍可被发现。
   **停止接收** 会关闭监听；切回发送模式会先停止接收，再恢复发送端发现。

角色选择会跨启动保存。关闭控制窗口会继续运行，退出应用则结束连接。
睡眠会关闭接收；唤醒后，如果先前开启接收，会恢复监听，请从发送端重新连接。
每次只允许一个发送端，额外连接会被拒绝，需先断开当前会话。

## 权限和范围

macOS 提示时，请允许本地网络访问和防火墙入站连接。接收模式不需要屏幕录制或
辅助功能权限。发送需要屏幕录制；仅向 Mac 显示画面不需要远程输入的辅助功能权限。
不要通过全局关闭防火墙来解决发现问题。

现有传输使用**未加密、未认证的 TCP**，仅适用于可信局域网。开启接收后，
局域网内的发送端可连接，没有配对码或身份认证审批。
Bonjour 服务是 `_opensidecar._tcp`，视频和控制使用 TCP 9000，不提供远程关机。

Mac 接收协商硬件 HEVC 并可回退 H.264，最高 60fps，横屏解码上限为 4096×2304，竖屏为 2304×4096。
较大的桌面会按比例缩小传输，桌面布局保留接收屏幕的逻辑点尺寸和 1×/2× 缩放。
HEVC 要求双端硬件支持和明确的接收能力声明，否则使用 H.264；120fps 偏好不会覆盖 Mac 能力限制。fps 标签统计送入显示渲染器的帧，
不代表实测屏幕刷新保证。iOS/Android 能力协商保持独立。

本功能不包含音频、接收端向发送端回传键鼠、同时双向视频或互联网穿透。局域网模式支持识别并绑定 Thunderbolt Bridge／链路本地以太网候选，见[直连使用指南](hevc-wired-pencil.zh-CN.md)。普通 USB-C 线本身不保证网络能力。扩展模式继续依赖私有
`CGVirtualDisplay` API，存在系统版本兼容风险。

## 构建和验证

```bash
./script/build_and_run.sh
# 以接收模式启动开发应用，并关闭自动发起连接：
./script/build_and_run.sh --verify -macRole receiver -autostart NO
./tools/run-swift-self-tests.sh
# 交互式桌面检查，会短暂创建并移除测试窗口和虚拟显示器：
./tools/run-mac-receiver-window-test.sh
```

脚本生成 Xcode 工程，构建具有独立 bundle ID 的 ad-hoc 签名 Debug 应用。
Codex 的 Run 操作使用同一脚本。
网络自检使用随机回环端口，不广播 Bonjour；覆盖 hello、拒绝第二发送端、真实
VideoToolbox H.264／HEVC 参数集、编码回退与超时、畸形长度、重连、断开和停止/重启隔离。
策略测试覆盖 5K 缩放、1× 几何、codec/fps 限制和分片/粘包。

仍需两台实体 Mac 验证互换方向、扩展/镜像、Wi-Fi/以太网、Retina/非 Retina、
显示器切换、睡眠唤醒，以及 30 分钟和 2 小时耐久性。本地自动测试不能证明
局域网延迟或持续 60fps。宣称性能前应记录硬件、系统、分辨率、codec、传输和
实际渲染结果。

参见[设计与上游合并评估](mac-to-mac-design.zh-CN.md)。

计入已完成的释放验证。
