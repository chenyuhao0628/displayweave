# DisplayWeave v0.3.3

发布日期：2026-10-27。正式版，Mac 构建号 / Android 版本号 **22**。已审核原生实现为 `bc928c3c26128ab690b0193801c8d363869fdd87`；上一正式版为 v0.3.2（21）。

## 改动

- Mac 扩展桌面新增自动匹配：参考可用的发送端邻屏或主屏、接收端宽高比与合理的系统报告物理尺寸。尺寸缺失或不合理时按比例估算。应先让接收端在目标显示器全屏；窗口模式和不准确的屏幕报告可能改变结果。
- 新安装默认自动匹配。已有安装保留已选档位和旧默认行为；在对应设备的“桌面大小”中选择一次“自动匹配”。没有有效安装身份的旧接收端继续跟随接收屏幕；iOS 和 Android 仍使用接收端几何。
- 对发送端屏幕变化采用防抖和冷却，仅在几何改变时重建对应会话；参考屏暂不可用时保留当前桌面。连接行分别显示实际桌面与协商视频尺寸，视频 raster 小于 backing 像素时提示。
- Mac 接收端新增可选物理尺寸字段，仍接受旧版公告。建议两台 Mac 均更新，以利用可用的尺寸信息；字段未知或非法时回退，不拒绝连接。原有帧格式、身份和偏好保持兼容。
- 单独的客户证据采集器可识别已保存的自动桌面选择和默认值，不导出原始设备 ID。

使用方法见[桌面分辨率](../guides/desktop-resolution.zh-CN.md)，检查与验收边界见[验证记录](../verification/automatic-desktop-matching.zh-CN.md)。

## 重要限制

自动匹配是估算，并非实体尺寸校准。Apple 视频范围仍为 **4096×2304**；本版不提供原生 5K 视频，5120×2880 桌面仍可能发软，也不能据此断定所有模糊的原因。客户双 Mac 效果，包括 2560 点 / 5K 情况，尚未实机验收。

## 兼容与验证

Mac ZIP 与引导式 DMG 使用与实际下载的 v0.3.2 应用相同的 Apple Development 身份，已验证 arm64/x86_64、加固运行时和嵌套签名。**应用仍未公证。** Sparkle 原公钥与 Android 原签名证书保持不变。iOS arm64 IPA 是无签名自签输入包，不能直接安装。构建 21 → 22 的隐私权限延续未交互重测。

本地通过 65 组 Swift 套件与生产方法夹具、Mac 通用架构 Debug 和 iOS 模拟器构建、Android 测试/Debug/Lint、网站、双语文档、发行链接与维护检查、Apple↔Java TLS、Mac/iOS Keychain 和隔离安全 Android 接收端。首次一次性 iOS Keychain 模拟器启动超时，隔离重跑通过。安全 iOS 接收端首次通过 TLS/视频检查，但切后台监听检查停在 inactive 状态；隔离重跑全部通过。

扩展 Android 体验测试首次在设置对话框仍可见时未能定位主界面控件；隔离重跑通过合成视频比例、状态、指标、输入与后台检查。这不能确认生产代码的根因。

在具有独立在线显示器的 Apple M5 Mac 上，隔离 AppKit 和虚拟屏检查包含合成的 2048×1152 点 / 2× 案例。这不能证明双设备串流、Intel 运行、原生 5K 清晰度、延迟或耐久。实施、自动检查与实机验收分别记录在[验证记录](../verification/automatic-desktop-matching.zh-CN.md)中。
