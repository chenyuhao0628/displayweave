# DisplayWeave v0.3.4

发布日期：2026-11-09。正式版，Mac 构建号 / Android version code **23**。包含 PR #25、#27、#28 和 #29 中已审核的改动。最终原生源码为 `4401828`（含本次验证发现的两项生命周期修复）。上一正式版为 v0.3.3（22）。

## 改动

- Android 新增显式启用的实验性高帧率试验和后台保活行为。试验会放宽兼容模式的吞吐量声明门槛，但不能证明实际渲染 FPS 或持续硬件性能。后台服务在受支持的生命周期转换期间保留接收会话。
- 符合条件的 iPad 接收端新增默认关闭的“原生分辨率高刷（实验性）”选项，下次连接时生效。仅在选择后扩大 Apple 视频能力范围；这不是固定 120Hz 模式，系统调度、温度和电源策略都可能降低实际呈现刷新率。
- 加固帧边界、生命周期清理、解码器恢复和接收端输入／界面策略，并加入回归覆盖及审核修复。Android 接收服务替换后会忽略旧服务器的延迟连接回调，避免其改变新会话的前台保活状态。服务停止命令按序处理，防止立即断开在前台启动确认前将其取消。
- Mac 应用为 Dock 和应用切换器导出圆角图标切片。

这些试验保留现有线格式与应用身份。详见 [Apple 视频能力](../guides/apple-video.zh-CN.md) 和 [Android 接收会话控制](../reference/android-receiver-session-controls.zh-CN.md)。

## 上游审核

已获取 OpenSidecar 上游 `origin/main`（`0f44853`）。它与本项目共享祖先之后已有 417 个路径变更，产品树差异显著，因此未整体合并；本次发行范围已由上述 PR 覆盖。其他上游改动延期至单独的兼容性审核。

## 兼容与验证

Mac ZIP 与引导式 DMG 使用固定 Apple Development 身份，并延续实际下载的 v0.3.3 应用 designated requirement。产物包含 arm64/x86_64、启用加固运行时并验证了嵌套签名；**应用未公证**。Sparkle EdDSA 密钥与 Android 签名证书保持不变。iOS/iPadOS arm64 IPA 是无签名自签输入，不能直接安装。

本地验证通过：65 组 Swift 套件与生产方法夹具、Mac universal Debug 与 iOS 模拟器构建、Android 测试/Debug/Lint、网站/双语文档/发布检查、Apple 分发与签名/目录/文档/打包维护检查和 36 项品牌导出。Apple↔Java TLS、Mac/iOS Keychain 和隔离安全 iOS/Android runtime 均通过。扩展 Android 体验夹具还通过合成视频比例、默认简洁状态、即时指标切换、黑边拒绝触控、中心映射和静止长按。独立 CryptoKit 验证以应用内固定公钥核验 ZIP Ed25519 签名、长度和篡改拒绝。

初始隔离 Android runtime 在快速连接切换期间发生 `ForegroundServiceDidNotStartInTimeException` 崩溃。来源实例校验修复了旧服务器回调修改新会话的问题，但扩展体验测试又发现保活服务启动/停止仍有竞态。停止现通过排队命令交给服务处理，先确认前台启动再关闭，并用启动 ID 保护更新的请求。回归覆盖替换后的旧回调投递、连续 20 次立即启动/停止、进程存活和最终服务清理。首次网站检查还发现旧 v0.3.3 标签断言，更新后通过。系统 Python 拒绝全局安装依赖后，品牌检查依赖改用本地虚拟环境安装。

本次实机验证：因仅内置显示器在线、没有独立显示器，虚拟显示测试记为 **SKIP**。本次发行会话未进行 22 → 23 隐私权限交互升级、实体 Android/iPad 串流、Intel 运行或耐久测试。下述 iPad 测量是沿用的独立范围证据。

Android 高帧率与 iPad 原生分辨率高刷均属实验功能。请求或协商的帧率不代表实体屏幕的实际刷新率。双设备串流、持续高刷表现、Intel 运行和长时间可靠性仍需独立实机验收。

隔离 iPad 容量回放使用 13 英寸 M4 iPad Pro（2024）、iPadOS 27.2，在 120fps 目标下，经认证 Wi-Fi 开发隧道回放 60 秒预编码视频，每种编码解码 7,200 帧。Metal 实际呈现测得 HEVC 61.21 FPS、H.264 61.17 FPS。测试使用仅测试用的准入预算覆盖，不包含桌面采集或实时编码；这是解码／呈现证据，不代表普遍达到 120Hz。详见 [Apple 视频指南](../guides/apple-video.zh-CN.md)。
