# DisplayWeave v0.3.1

发行日期：2026-10-26。**正式版**，Mac 构建号／Android version code 为 **20**。原生源码基线：`c0f8f8a`，即 PR #19 的合并提交（审查版本为 `cd57957`）。上一正式版为 v0.3.0（19）。本次及后续版本均直接正式发布，不经过公开预览版或候选版阶段。

## 改动

- 修复重连与采集恢复的代际所有权。旧关键帧请求不能消耗新请求；采集中断后应用变化的接收端尺寸；旋转后保持显示器真实相邻关系。
- 限制编码器故障恢复。临时故障每轮最多重试三次，最多重建编码器两次，连续五秒健康输出后恢复预算。耗尽后停止会话，并给出重新连接／降低分辨率的恢复操作。
- 改善拥塞后画质恢复。Mac 编码丢帧本身不再判定为网络拥塞；健康且活跃的发送队列可以恢复。低于最初 Auto 目标时，每三秒健康窗口提高 20%；超过目标的探测仍为五秒／7%，Mac 仅凭本地证据恢复时不超过最初目标。
- Apple 接收端在短暂背压下保留参考帧链，范围为额外两帧／50 ms。iOS 同时解析当前与旧版发送端健康遥测；连接后 15 秒仍未收到有效首帧则退出等待，首帧后的静态桌面保持连接。
- Android 视频、光标与触控共用保持比例的矩形，黑边不发送远程触控。静止按住 120 ms 后开始按下；拖动、双指滚动、暂停与尺寸变化正确取消或结束所属手势；尊重系统旋转偏好。
- Android 在分配位图前限制光标解码；两级各 12 帧队列共享接收至提交解码器的 150 ms 期限。过期依赖帧会清理，并从新关键帧恢复。这是队列上限，不代表实测端到端延迟。
- 增加 Apple 分辨率／帧率优先与 30 fps 上限；展示请求和生效码率、编码尺寸、格式及目标 FPS。不可用的手动码率归一到最近有效值，镜像尺寸适配接收能力，Android 默认状态更简洁，iOS 大字号下设置入口保持可达。

[审计](../archive/audits/code-and-experience-audit-2026-10-26.zh-CN.md)保留基线证据；[升级记录](../verification/reliability-experience-upgrade.zh-CN.md)逐项对应 A01–A10 修复、参数决策、附加改进、回归与验收边界。历史探针刻意描述旧基线，当前回归套件验证修复后的行为。

## 升级与兼容性

发送端与接收端均升级后可使用完整改进。旧接收端保留经协商的兼容路径。已有显式指标和画质偏好保留；新安装 Android 默认简洁状态，详情在设置中查看。无效手动码率会归一。文字清晰度优先时选择**分辨率优先**，更重视运动流畅度时选择**帧率优先**；目标 FPS 不等于实测呈现 FPS。

Mac 打包与下载并校验过的 v0.3.0 ZIP 比较签名延续，包括 bundle ID、团队与 designated requirement。本次未交互复测构建 19 → 20 的隐私权限延续；早期固定签名覆盖安装证据见 [Mac 权限](../guides/mac-permissions.zh-CN.md)。首次从临时签名版升级仍可能需要重新授权。

**Mac 沿用 Apple Development 签名，未公证。** 核对校验和后安装到 `/Applications`，如被拦截，按文档使用**隐私与安全性 → 仍要打开**。Android 保持原项目证书。iOS IPA 是无签名 arm64 设备重签输入包，需要用户自己的有效 Apple 签名身份；不是模拟器下载或可直接安装的应用。

GPL-3.0、上游署名、project／bundle／package 标识、既有偏好键、配对、Bonjour 服务、线格式、Sparkle 密钥与 Android 证书保持不变。下载使用 GitHub Releases；[现有更新渠道](automatic-updates.zh-CN.md)使用 GitHub Pages。
