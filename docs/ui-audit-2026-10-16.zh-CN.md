# UI 审核与验收 — 2026-10-16

范围：Mac/iOS/Android 原生界面、同等可见的 OpenDisplay 连接入口、GitHub 发行 v0.3.0-preview.2（17）。设计依据：[UI 规范修订 2](ui-guidelines.zh-CN.md)。互通说明：[OpenDisplay 兼容指南](opendisplay-compatibility.zh-CN.md)。

## 问题与实现

| 问题 | 实现 |
| --- | --- |
| 发送端错误声称全部局域网流量未加密 | 主界面说明实际安全策略；活跃会话保留协商后的加密标记 |
| 连接准备、诊断与实时状态混杂 | Mac 工作区采用共享分组；设置划分连接/应用；接收配对置于显示/输入选项前 |
| 失败说明最多两行 | 设备/会话名称与错误完整换行，保留重试和诊断操作 |
| OpenDisplay 入口藏在安全设置中 | 三端主界面均提供同等连接模式选择；发送端可同时支持新旧接收端 |
| 早期 OpenDisplay 无安装 ID 的 hello 被拒绝 | 显式匿名旧版接入，修复前后回归；保留已知身份和 TLS 防降级 |
| 移动端引导文案分散，Android 设置无层级 | Apple 共用三步引导、限定移动内容宽度；Android 共用面板/标题/按钮样式和分组 |
| 权限状态依赖彩色图标 | Mac 权限行增加已允许/未允许/待检查文字 |

展示与传输/生命周期所有权分离。保留偏好键、bundle/package 身份、Bonjour 和 wire framing。不添加复述 UI 静态结构的测试。
