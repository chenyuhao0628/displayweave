# DisplayWeave UI 设计规范

修订 2 · 2026-10-16。本文是 macOS、iOS、Android 应用 UI 的实现约定。网站沿用相同品牌词汇和下载真实性要求；本轮改造原生应用与发布信息。实际证据单独记录在 [UI 审核](ui-audit-2026-10-16.zh-CN.md)，不能把设计要求当作已通过验证。

## 产品与信息架构

帮助用户把另一台设备用作显示器。首屏必须回答：本机是什么角色、现在是什么状态、下一步做什么。使用原生控件与系统字体，详细调优退出首次连接主路径。

| 界面 | 顺序与主要操作 | 次要内容 |
| --- | --- | --- |
| Mac 发送端 | 角色 → 显示模式/连接方式 → 设备 → 首次连接帮助；选定设备后连接 | 配对与权限恢复；画质放入设置 |
| Mac 接收端 | 角色 → 实时接收状态与配对 → 显示选项 → 可选键鼠回传 | 连接步骤与网络排障 |
| Mac 设置 | 串流 / 通用 / 权限与诊断 / 安全与配对 | 按用户目的分组，说明位于对应控件下 |
| iOS / Android 等待页 | 品牌 → 设备/状态 → 三步引导 → 配对与连接设置 | 设置与帮助；首次引导/帮助中提供 Mac 下载 |
| 接收画面 | 黑底、保持宽高比的视频与常驻可访问设置按钮 | 可选实测诊断；等待卡片不覆盖视频 |

Mac 工作窗口初始 680 × 720 点，最小支持 480 × 440；菜单栏面板为 480 × 640，内容可滚动，提供“打开窗口”。头部与底部保持可达。接收设置和配对入口不得埋在长篇说明后。移动端内容居中，内容最大宽度 520 点/dp（不含页面边距），横竖屏均可滚动。文本容器不固定高度。

## 布局与组件令牌

| 令牌 | 规则 |
| --- | --- |
| 间距 | 4、8、12、16、24、32 逻辑点/dp；分组间距 24；页面边距 20–24 |
| 字体 | 页面用系统 title/title2；分组/设备用 headline；操作与说明用 body；辅助内容用 caption/footnote |
| 测量值 | 码率/FPS 使用等宽数字；标识符可使用等宽字体并支持选中 |
| 表面 | 原生自适应窗口背景/材质；安静的次级卡片；Android 使用明确的日夜语义色 |
| 强调色 | 统一蓝色主要操作；状态同时有图标和可读文字 |
| 形状 | 内容卡片圆角 16；原生按钮/开关形状；紧凑状态区域圆角 12 |
| 点击范围 | Mac 原生控件；iOS 触摸操作至少 44 点，Android 至少 48 dp |
| 描边 | 轻量分隔线；不使用装饰渐变、多余阴影或过大的图标容器 |

可复用组件只承担一种职责：分组标题、内容面板、状态标签、设备行、编号步骤。Apple 首次引导与等待页共用步骤组件；Android 样式收敛到 ReceiverUi。不要复制整页，也不要在视图 body 中执行网络操作。

## 状态与交互约定

| 状态 | 展示 | 可用操作/恢复 |
| --- | --- | --- |
| 发现中/等待 | 天线图标、等待文字和连接步骤 | 配对设置、权限/网络帮助 |
| 已发现设备 | 名称与连接方式；链路本地有线只称候选 | 连接；不得宣称已建立会话 |
| 启动/恢复中 | 会话实际状态与等待图标 | 断开/取消；替换期间禁止重复启动 |
| 串流中 | 会话文字、实际安全模式与传输；指标从属展示 | 断开；失败会话提供重试 |
| 失败 | 错误文字完整换行，不限制为两行；警告图标 | 重试与相关权限/配对入口 |
| 切换角色 | 进度与资源释放说明；角色控件禁用 | 等待所有权移交 |
| 已停止接收 | 真实停止状态 | 开始接收 |

每个决策区域只有一个主要操作。停止/断开有明确文字并保持次要样式。不得用 TCP 建连成功推断协议就绪或加密。安全偏好摘要描述策略，活跃会话展示协商结果。默认说明需要配对；允许旧版时说明“允许未加密兼容”，不能声称所有连接都未加密。安全发送端不得出现无条件的明文警告。

## 文案、可访问性与语言

统一 Send/Receive（发送屏幕/接收屏幕）、Extend/Mirror（扩展/镜像）、LAN（局域网，Wi-Fi 或以太网）、USB、Waiting（等待连接）、Pairing（配对）、Retry（重试）、Disconnect（断开）。错误提供下一步。明确在接收端生成邀请、在 Mac 导入；配对不等于授予 ADB 或辅助功能权限。

状态必须有文字和图标。装饰图片对辅助技术隐藏。纯图标操作提供可访问名称。长设备名、错误允许换行。表单字段即使隐藏视觉标签也必须保留语义标签。使用原生键盘 Tab 导航、可见焦点和 Command-comma 设置快捷键。移动端支持 Dynamic Type/字体缩放与滚动，不强制全大写、不固定文字高度。次级文字采用语义对比度，不用过低透明度。跟随系统外观；黑色用于视频。不把逐帧变化的性能值持续播报给辅助技术。

用户指南提供中英文互链。当前原生 UI 为简体中文；完整英文应用本地化属于独立工作，不能用双语文档暗示已经实现。

## 所有权与兼容

MacRoleController 管理互斥的发送/接收切换。SenderController/DeviceSession 管理传输与清理；视图只绑定既有状态。ReceiverModel/PhoneReceiver 与 Android MainActivity 保持生命周期和解码器所有权。界面改造保留偏好键、bundle/package ID、服务名、协议 framing、更新源和签名身份。从 project.yml 生成 Xcode 工程。

HEVC、高刷新率、有线候选和 Pencil 保留能力与实测限定。目标 FPS、送入显示层 FPS 不等于屏幕实测刷新率。设置区分用户授权与已协商的协议支持。源码能力只有在对应版本发布后才能写成可下载能力。

## 验收与证据

发布前构建两个 Apple target 与 Android，运行项目回归和文档检查。有可用显示会话时，检查 Mac 发送/接收/设置的最小及默认尺寸、深浅色、长文本、键盘导航；检查移动端等待/首次引导/设置、横竖屏与大字体。可用时使用隔离 fixture 验证视频与失败状态，并注明合成证据。

分别记录已实现、自动化检查、界面观察、物理设备结果、SKIP/延期事项。不伪造连接截图。虚拟显示器测试必须有独立在线显示器，否则 SKIP。模拟器或编译通过不证明双设备性能、VoiceOver/TalkBack 体验或 Intel 运行情况。
