# UI 规范

范围：macOS 控制与接收窗口、iOS 接收端、Android 接收端、双语网站。2026-10-16 生效，是源码分支的实现约束。

## 信息与交互

- 优先展示主要任务：选择发送/接收、选择设备、连接；接收端展示就绪状态与 Mac 端操作步骤。诊断和调优不挤占首次连接路径。
- 统一术语：发送 / 接收、扩展 / 镜像、局域网（Wi-Fi 或以太网）、USB、已连接 / 等待连接 / 连接失败。协议名称放在高级设置或诊断中。
- 状态必须有文字，不只靠彩色圆点。错误提供重试、权限设置或网络检查操作。正在建立连接不能显示成已连接。
- 每个上下文一个主要操作，次要操作使用系统边框或文字控件。断开/停止保持明确标签，不把失败静默显示成成功。
- 在连接帮助附近说明本地传输安全边界。区分源码功能、实验性能与已发布下载。

## 视觉变量

| 用途 | 规范 |
| --- | --- |
| 间距 | 4、8、12、16、24、32 逻辑点/dp；区块 24；页面内边距 20–24 |
| 字体 | 系统字体；语义化标题、正文、说明；等宽仅用于测量值和标识 |
| 背景 | Apple 系统背景与分组次级背景；Android 自适应明暗色板；网站共享 CSS 变量 |
| 强调色 | 一个蓝/青主操作色；绿/橙/红只用于有文字的状态 |
| 形状 | 内容面板圆角 12–16；系统控件形状；避免过度装饰 |
| 点击区域 | 桌面原生控件；iOS 触摸至少 44 点、Android 48 dp、网站触摸操作 44 CSS px |
| 宽度 | 桌面可调整且可滚动；移动端内容至多 520 点；网站至多 1240 px |

## 平台约束

**Mac：** 入口、发送控制器/会话模型、权限、通用 UI 与功能视图分文件。主窗口展示角色、设备与连接控制；独立设置窗口容纳画质、应用显示方式和诊断。AppKit 仅负责窗口生命周期/视频桥接。菜单栏面板大小受控，主窗口可调整；保留键盘操作和 Command-comma 设置入口。

**iOS：** 等待/引导页面可滚动，支持横屏与动态字体。串流期间设置入口可见且可访问，摇动只作为可选方式。视频保留黑底和正确比例。将模型、视频桥接、性能面板、设置与引导从应用入口分离。

**Android：** 保留沉浸式视频，等待时展示可访问的连接面板。通用间距、色彩、文字/按钮样式由 UI 辅助类管理；支持明暗模式与小屏滚动。保留触控、解码与生命周期所有权和明确的更新操作。

**网站：** 使用可复用区块与共享变量；移动端与桌面均可导航，键盘焦点可见，语义化区域，尊重减少动态效果和双语标签。开发能力不能改变已发布下载的描述；保留下载产物检查。

## 验收

检查明暗、最小尺寸、长文本；桌面/网页键盘导航；移动端横竖屏及增大字体。覆盖等待、连接中、已连接、失败、角色切换与设置。受影响平台构建和状态策略测试逐轮把关；仅能用硬件验证的状态进入物理矩阵，不伪造截图。在迭代报告中区分已检查与未测试状态。

## 源码功能状态：HEVC、直连与 Pencil

接收状态显示协商后的编码。未连接的链路本地有线 Mac 标记为候选，活动会话显示绑定接口，自动连接开关默认关闭。Pencil 设置区分已确认的压感／倾角协议与兼容触控，并说明硬件／应用要求；不得把协议确认表达为实机验证通过。
