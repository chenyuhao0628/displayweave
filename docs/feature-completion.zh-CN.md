# 功能补全方案与证据

基线：`89d7d20`，2026-10-16。本文是当前源码开发台账；已安装和已发布的 p8（build 15）不随本轮开发改变。实机验收单独记录。历史审计保留其当时证据，待办清单以本文为准。

## 范围、可行性和验收

| 编号 | 当前缺口与目标行为 | 方案与兼容边界 | 完成证据 |
| --- | --- | --- | --- |
| F01 | 内置 GitHub Pages 更新源不可用，新构建需要可达入口。 | 主更新源迁移到已有 HTTPS Cloudflare 镜像，保留 Sparkle Ed25519 和 APK 证书身份。Android 仅传输失败可回退一次，元数据非法和文件完整性失败不得回退。旧 p8 的原地址若持续不可用，需要手动安装一次。 | 迁移配置测试、回退拒绝用例、平台构建、在线 feed 检查。 |
| F02 | 画质仅缩放编码，缺少各设备独立桌面分辨率。 | 按安装身份保存原生/1080p/1440p/4K；明确像素与逻辑点、方向、接收能力上限。等待所属资源停止后，仅重建受影响的扩展会话。镜像保持实体桌面尺寸。 | 几何、持久化、上限、会话替换测试及 Mac 构建；真实显示器验收独立进行。 |
| F03 | 局域网视频和控制没有加密认证。 | 基于平台密码库建立显式协商的安全传输、带外配对确认、可信设备保存和撤销；认证之前禁止采集与输入。握手有时限，已配对设备拒绝降级。旧协议仅可通过明确的不安全选择兼容。最终密码和传输方案在 API 与跨平台互操作核实后确定。 | 正反握手、错误身份、篡改、重放、超时、重连、旧端兼容用例，Apple/Java 和真实网络集成。 |

| F07 | Pencil 缺少旋转、挤压/双击动作和橡皮工具。 | 版本化扩展、SDK/硬件保护、可配置工具/快捷键动作和取消；使用有文档的数位板字段。应用适配是显式快捷键映射，不承诺所有绘图软件通用。 | 数据/校验、动作映射、能力和取消测试及 Apple 构建；实机 Pencil/应用矩阵独立待验。 |

## 执行与完成定义

顺序：F01 → F02 → F04 → F08 → F06 → F03 → F05 → F07 → F09 → F10/F11 → F12。每轮执行相关回归和构建、更新双语指南并独立提交。安全方案核实可能调整顺序，须在本文记录实际取舍。不需要并行代理。

完成必须有真实实现与自动验收，不能只有策略占位或设计。外部证书/素材条件缺失时，交付可用工具并明确标记仍阻塞的外部部分。开发不隐含发行或覆盖安装。合入前运行全部 Swift 套件、Android 测试/构建、两个 Apple 构建、网站生产构建、双语/发布和空白检查。保留无关改动，仅同步 `displayweave`。
