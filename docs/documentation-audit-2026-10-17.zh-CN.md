# 文档检查与发行一致性（2026-10-17）

本轮针对 v0.3.0-preview.3（18）检查根目录指南、文档索引、当前安装／更新／签名／发行流程、OpenDisplay 兼容、分辨率说明和网站文案，并对全部受版本控制 Markdown 执行本地链接目标扫描。

## 已修正

- 首页、架构、安全说明、路线图和网站中把当前 Mac 描述为临时签名的旧文字，改为固定 Apple Development 签名、未公证。
- 当前版本、八项资产名称、二进制／更新源哈希、网站结构化版本与原样保存的在线更新源统一为 preview.3／18。
- Mac 首次签名迁移与后续身份延续分开说明；不再承诺每次升级都需要重新授权，也不承诺永久保留权限。
- 自动更新中文旧文案中的“双源”，以及旧 p8 记录中的镜像下载指引，改为当前 GitHub 单源规则。p8 本地产物与公开发行状态明确区分。
- 当前发行采用本地流程；托管 Release 缺少 Mac 身份、前版基线和源码归档步骤，不能直接视为完整发行途径。
- 构建示例明确固定签名要求；下一版示例使用 preview.4／19 并明确不是已发行版本。双语检查补入此前遗漏的权限指南、八组已有文档和本次发行／检查记录；为七组文档补齐语言互链。
- 历史发布说明保留原版本签名和测试事实；旧性能观察不改写成本版实测。当前兼容入口和扩展分辨率行为没有改变。

## 验证与边界

网站构建、93 组双语配对、当前发行链接／哈希／feed 一致性检查通过；208 份 Markdown 的本地链接目标扫描通过。发行 PR 记录这些检查。完整托管 CI 必须通过才合并。产物验证、build 17.1 → 18 本机权限保留和未执行的实机项目分别见[发布说明](release-notes-v0.3.0-preview.3.zh-CN.md)。

本地链接扫描不证明每个外部网站持续在线；本次发行另行验证 GitHub Release 附件和 GitHub Pages 更新源。跨设备画面／性能、Intel、Pencil 与耐久仍待实机验收。旧历史报告可能描述过去实现，以当前用户指南和带版本的发行说明为准。
