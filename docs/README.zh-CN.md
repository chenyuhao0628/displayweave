## 证据用语

**已实现**指源码行为；**自动化验证**说明测试与版本；**实机验证**注明真实硬件、配置和时长；**实验功能**表示表现依赖硬件；**待完成 / SKIP**表示尚未验证或完成。目标 FPS 不代表实测渲染 FPS。当前边界见 [v0.3.1 发布说明](releases/v0.3.1.zh-CN.md)。
