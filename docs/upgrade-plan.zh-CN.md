# 源码升级计划 — 2026-10-16

基线：`83581c5`；当前分支 `codex/mac-to-mac-lan`；现有 PR #11。公开版本仍为 v0.2.1-p6。

1. 规则：建立 AGENTS.md 和带日期的 Codex 官方依据；双语/发布文档检查后提交。
2. UI 约束：盘点 Mac（1434 行混合入口/控制器/视图）、iOS（796 行混合 UI/模型）、Android 程序化接收面板和 React 网站；制定规范并提交。
3. Apple UI：分离职责，建立桌面连接工作区/设置，自适应接收页面及可访问的串流设置；编译两目标并运行 Swift 自检后提交。
4. Android/网站：集中样式，自适应等待/帮助页面，移动导航和语义化区块；Android 测试/构建、网站类型/构建与 UI 检查后提交。
5. 上游：刷新 origin/main，按本地兼容约束筛选行为修改，保留署名并用回归测试验证；记录冲突和延期功能，提交。
6. 审计：检查生命周期、网络边界、旧回调隔离、可访问性和发布声明。修复有证据的问题，运行完整回归，将实际结果写入架构、路线图及审计后提交并同步远端。

终点：四个现有 UI 界面落实规范，上游有用项目有处理结论，重要审计问题解决，自动化通过，main/远端整合得到验证，物理验证保持如实标注。不包含公开发版或未经验证的双机性能承诺。

完成结果、各轮提交与验收边界见[源码升级报告](source-upgrade-audit-2026-10-16.zh-CN.md)；最终远端检查与合并记录见 PR #11。
