- **iOS：**页面、等待、引导、设置、性能、模型和视频适配器拆分。等待说明与设置可滚动；播放时提供可见的 44 点设置按钮，保留可选摇动入口。引导明确区分镜像和扩展。
- **Android：**`ReceiverUi` 统一 dp 间距、昼夜配色与控件；等待内容限制最大宽度，按连接方式组织说明，设置可滚动，隐藏性能叠层后仍可打开设置。
- **网站：**统一 token 与语义区块，改善键盘/触摸导航；移动菜单支持 Escape 和导航后关闭；双语元数据、焦点状态和 Mac 接收功能的源码范围说明齐全。静态输出与 hydration 对齐，清除未用组件/依赖，`pnpm build` 包含 TypeScript 与生成页面断言。

## 审计修复与证据

| 问题 | 修复及验证 |
| --- | --- |
| iOS 未校验 32 位负载长度 | 两个 Apple 接收端共用 `Shared/ReceiverFrameDecoder`，在累计负载前拒绝零长度和 >16 MiB。实际旧模拟器应用未通过无效长度回环测试，更新后通过。 |
| iOS 旧 socket/listener 回调可能影响替换连接 | 生命周期归属串行队列，校验监听身份/generation，立即分离旧连接，goodbye 仅操作捕获的旧 socket，重试受限。模拟器验证替换后存活、重连和后台停止监听。 |
| 游标图片像素分配与几何缺少限制 | 共用解码器在分配像素前检查元数据；图片 ≤512×512，base64 ≤256 KiB，锚点和归一化尺寸必须有限。回归覆盖压缩后的超大图片、无效几何、超大输入及合法图片。 |
| 对端几何或滚动转换可能溢出 | 算术前验证尺寸与像素面积；拒绝非有限坐标，限制归一化输入与滚动转换。极端整数/浮点测试通过；停止、更换捕获目标和断线会释放中断的拖拽。本轮尚未实测 CGEvent 操作。 |
| 权限轮询持有自身 | 定时器弱引用并在析构时失效；生命周期回归在修复前失败、修复后通过。 |
| Android 写入阻塞时控制消息积压 | 一个写线程、128 个排队任务、每条控制负载 ≤64 KiB；两个读线程、两个排队任务。溢出关闭对应连接，避免只丢失抬起事件。阻塞写线程测试在修复前失败，修复后连同替换/旧发送/超长覆盖通过。 |
| 失败或替换的发送管线可能滞留资源 | `SessionLifetime` 保证一次清理、等待挂起的启动结束、失败自动释放；设置/传输替换与 Android 恢复等待旧清理，角色/传输不再允许时移除迟到的 ADB 结果。 |
| Apple 日志没有总量限制 | 当前与上一文件各 ≤2 MiB，单条 ≤8192 字节，排队 ≤256 条；轮转、并发、UTF-8 截断和背压测试通过。 |
| 双指滚动可能先触发点击 | 单指按下延至抬起、10 点拖动或 0.12 秒按住；第二指取消待提交点击。纯策略测试通过，真实触摸仍待验收。 |

## 明确保留的验收项

1. **双 Mac 真机：**双方向、镜像/扩展、Wi-Fi/以太网、显示器热插拔、真实睡眠唤醒、macOS 14/15 与 Intel 运行。记录 codec、分辨率、目标/实际 FPS、重连时间和内存，按 [Mac 互联验收](mac-to-mac.zh-CN.md)执行。
2. **Mac 视觉与虚拟显示器清理：**开发应用已启动，但当前合盖/无独立显示器会话无法获得有效窗口截图；本轮未新建虚拟显示器。需在独立在线显示器下复核主界面、设置、菜单、接收、全屏和清理。较早的合成显示器证据保留于 Mac 设计报告，不算本轮 UI 通过。
3. **Android 视觉与移动端输入：**本轮没有可用 Android 模拟器镜像或已连接真机。需复核明暗、字体、旋转、系统栏、无障碍与播放中设置；iOS/Android 均需真机复测点击、拖动、双指滚动。
4. **耐久：**双 Android、同条件 USB/Wi-Fi、30 分钟与 2 小时测试仍待完成。构建、策略与模拟器证据不能证明持续 60/120fps。

这些验收项限制运行和发布声明。本轮以源码范围完成、自动门禁通过为结束标准，不把硬件矩阵写成已完成。
