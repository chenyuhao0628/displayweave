隐私与本地数据

2026-10-27 更新 · 适用于 DisplayWeave v0.3.3 的 Mac、iOS/iPadOS、Android 应用与本网站

English | 简体中文

DisplayWeave 在你的设备之间直接传输屏幕视频和输入。应用不包含分析统计或自动崩溃上传服务。下文说明本地发现、性能诊断、配对记录和软件更新请求。

屏幕、输入与连接数据

Mac 采集选定的物理或虚拟显示器，编码后发送给已连接的接收端。受支持且已启用的触控、键盘、指针与性能消息通过会话回传。Mac 接收端也可能通告系统报告的屏幕尺寸和实体大小，帮助发送端估算桌面几何。DisplayWeave 不提供云端串流中继，也不会自动上传屏幕视频。

  • Apple USB 使用 macOS usbmuxd；Android USB 使用已授权的 ADB 转发，均为本地线缆／隧道路径。
  • 局域网串流通过 Wi-Fi 或以太网在设备之间直连。Bonjour／NSD 发现会广播本地服务元数据，包括所使用的名称、能力和安装标识；同网络中的附近设备可能看到发现信息。
  • 每个接收端拥有独立会话。视频缓冲是临时数据；诊断日志和基准记录属于另外保存的本地数据。

加密与配对

v0.3.3 的 Apple 与 Android 默认使用固定证书指纹的双向 TLS 和邀请配对，USB 隧道也相同。信任记录保存在本地供重连使用。邀请短时有效、只能使用一次并仅存于内存，请勿公开分享。参见配对与撤销。

显式启用的旧版 OpenDisplay 兼容连接不加密，仅在可信设备与网络中使用。ADB 授权还会单独授予 Mac 对 Android 设备的调试权限，不再需要时可在 Android 开发者选项中撤销。

本地存储

数据用途与位置
偏好与安装标识本地保存画质、连接选择、按设备设置，并识别不同传输下的同一安装。安装与设备元数据也可能通过服务发现和会话交换。
配对身份与可信设备私钥使用 Apple Keychain 或 Android Keystore。平台安全存储在本地保存设备名称、标识、证书指纹及信任／撤销状态。可在安全设置中撤销设备或重置本机身份。
诊断与基准记录本地应用／系统日志和选定基准记录描述连接、时序、队列与性能。DisplayWeave 不会自动上传。分享日志或截图前请检查并脱敏。
更新文件Mac 与 Android 更新组件可能在本地缓存下载包，以供校验和安装。

更新检查与本网站

Mac 和 Android 更新检查会请求项目 GitHub Pages 更新源。安装包通过 HTTPS 从 GitHub Releases 及其下载基础设施获取。托管方会因此收到常规连接／请求元数据，不会收到屏幕串流。iOS 没有 DisplayWeave 自动更新通道。详见更新行为与完整性检查。

本网站由 GitHub Pages 托管，网站源码不含分析／追踪脚本或基于 cookie 的跟踪。托管方可能处理常规请求数据，其做法见 GitHub 隐私声明。打开外部链接时使用目标网站的服务。

权限

  • 屏幕录制用于采集所选 Mac 显示器。
  • 辅助功能用于注入受支持且已启用的远程输入。
  • 系统需要时，本地网络权限用于局域网发现与连接。
  • Android USB 调试和 RSA 授权用于 ADB 转发；APK 更新还需要 Android 安装权限和系统确认。
